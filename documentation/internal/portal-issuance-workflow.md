# Portal issuance workflow

An administrator explicitly creates a request, copies its token to the Naxas portal, and later explicitly checks status. Approval alone never activates the CMS: the returned detached license must pass the existing local RSA/SHA-256 provider and product, domain, installation UUID, Single Site type, and expiry checks before persistence. Invalid retrieval preserves an existing valid license. No scheduled/page-request polling is implemented in this foundation.
