# Read Me First

Buildora CMS requires PHP 8.2+, the listed PHP extensions, and MySQL/MariaDB. Read the installation and server-requirements guides before upload. The source package requires Composer and Node; the shared-hosting package is prepared with production dependencies and compiled assets. Point the web root to `public/`, then visit `/install`. Only the manual/offline signed-license provider is operational. Marketplace adapters and an automatic updater are not included.
