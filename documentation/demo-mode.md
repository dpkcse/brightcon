# Demo mode and licensing

“Demo” is an explicit installation seed-data choice, not a licensing state or runtime entitlement switch. It cannot grant activation, bypass RSA verification, change warnings, or take public pages offline. A valid license does not disable demo-data safeguards, and changing demo seed settings does not mutate stored license state.

Installed/unlicensed, installed/licensed, demo-data/unlicensed and demo-data/licensed combinations therefore use the same independent license policy. See `seed-modes.md` for the separate production acknowledgements that govern demo data.
