# Support Policy Template — Owner Approval Required

This template is non-operative until the product owner approves and publishes it.

Proposed included support: confirmed product defects, documentation clarification, version-specific technical guidance, and security-update notices according to the approved commercial terms.

Proposed exclusions: custom development, hosting administration, third-party server failures, content entry, debugging buyer-modified code beyond standard support, domain or DNS management, and data recovery without valid backups. This template does not promise unlimited support and is platform-independent.
